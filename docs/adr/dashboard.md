# Dashboard SPA

- **`Bun.build` plus an in-house router** (`src/web/router.js`, `routes.js`), not wouter: pages use the `next/navigation` names (`useRouter`, `usePathname`, `useSearchParams`, `useParams`, `Link`, `redirect`), so keeping their shape keeps page bodies unchanged. `router.refresh()` only re-notifies subscribers (no server components); `{ scroll }` is accepted and ignored. `lazy()` modals/charts (recharts, `@xyflow/react`, `@dnd-kit`) keep the initial JS under the budget in `tests/web/build.test.js`; the topology draws its own edges because the built-in animated edge marches a `stroke-dasharray` on every edge; `DashboardLayout` renders one nav (`TopBar`, or `PhoneTabBar` on phones), never two copies (doubled prefetches and duplicated the accessibility tree). Where: `src/web/`.
- **No `Bun.serve` HTML import**: its opaque `HTMLBundle` leaves no point to inject per-request boot data (`window.__LR_BOOT__`: `timeZone`, `gaId`, `requireLogin`, `locale` from the cookie) and head tags. The build writes `index.html` plus assets to disk; `serveSpa` rewrites `index.html` with `HTMLRewriter` after the guard; `/assets/*` is served immutable from the same directory. Where: `src/server/spa.js`, `static.js`, `src/web/boot.js`.
- **One dev build directory per process** (`dist/web-dev/<pid>`, rebuilt when `src/` or `open-sse/` change): two dev servers sharing an outdir delete each other's chunks mid-request. Removed on exit; a dead pid's directory is pruned on the next start; builds serialize on one promise chain. Where: `src/server/spaBuild.js`.
- **A missing production build answers 500** ("dashboard is not built"); with `NODE_ENV=production` or `LITEROUTER_SPA_DIR` set the directory is only read, never built. Where: `spaUnavailableResponse`, `src/server/paths.js` `SPA_DIR_OVERRIDE`.
- **ESLint has no `eslint-config-next`** (its parser requires `next/dist/...`, which no longer exists): flat config with `eslint-plugin-react`, `react-hooks`, `jsx-a11y`, `import` and `local/no-comments`; the six React Compiler rules and `exhaustive-deps` stay warnings; default espree parser, `cli/cli.js` is `commonjs`. Where: `eslint.config.mjs`.
- **Provider card counts use the detail page's auth rules**: dual-auth providers store keys as `apikey` or `api_key`; Kiro has no `authModes` but accepts both; free-tier/API-key providers (cloudflare-ai, byteplus, ollama, vertex) default to apikey support; count by per-provider `dualAuthTypes`; the enable toggle follows the same rule; `noAuth` providers are always usable and never "none". Where: `src/web/pages/dashboard/providers/utils.js`.
- **Client-only values (timezone, origin, theme) must match first render**: the app timezone comes from boot data; `useOrigin` renders empty first; the persisted theme is applied before first paint by an inline script in `index.html`. Where: `src/shared/utils/dateTime.js`, `src/shared/hooks/useOrigin.js`.
- **Route Sheet colour rules**: one token set (`bg`, `raise`, `line`, `line-strong`, `ink`, `muted`, `faint`, `bar`, `mark`, `mark-line`, `ok`, `danger`, `warning`, `wire`, `wire-live`, `grid`) defined for light and `.dark`; the old alias and `brand-*` scales are gone. `mark` means now/current only, `ok` healthy, `danger` failing; nothing else is coloured. No gradients; `backdrop-filter` only on the sticky top bar; shadows (`--shadow-float`) only on modals, drawers, menus and sheets. Lines on light use `mark-line` (`#a37a00`), since `mark` (`#ffd23f`) is about 1.5:1 on white. Where: `src/web/globals.css`.
- **Fonts are emitted as hashed `.woff2` files, not inlined**: `Bun.build` inlines `url()` fonts under about 100 KB even with a file loader, which put about 115 KB of base64 in the main CSS. Where: `src/web/build.js` `fontAssets`.
- **One nav list feeds four views**: top bar at ≥ 1360px and only while its links fit (a `ResizeObserver` folds it to Menu, with hysteresis so it cannot oscillate), a full sheet on tablets, and on phones a bottom tab bar (four `primary` items plus More) that hides while a text field in `main` has focus. Where: `src/shared/components/nav/navItems.js`, `src/shared/components/shell/`.
- **Escape closes only the topmost layer**: Modal, Drawer, the nav sheets and menus register with one layer stack instead of each listening on `document`. Where: `src/shared/hooks/useEscapeLayer.js`.
- **Phone tap targets are at least 44px** through `max-sm:` heights on the base controls and on page-level text links; desktop sizes stay 28–36px. Where: `src/shared/components/Button.js`, `Input.js`, `Select.js`, `SegmentedControl.js`.
- **Reduced motion unmounts decorative motion instead of styling it**: CSS `animation: none` does not stop `<animate>`/`<animateMotion>`, and the global reduced-motion rule only shortens CSS animations to one 0.01ms run, which would leave comets parked at their keyframe ends. So the Overview packet and every topology comet, glow, ripple and orbit are not rendered under `prefers-reduced-motion`; edges, cards and the router keep their static highlight colours, and the status-dot rings are hidden by CSS. Where: `src/web/pages/dashboard/overview/RouteWires.js`, `src/web/pages/dashboard/usage/components/TopologyMotion.js`, `ProviderTopology.js`.
- **The provider topology is the one maximal-motion surface, and the one place glows are allowed**: the owner asked for "motion maxing" there, because it is the only ambient live view (a graph you watch while traffic flows), while every page you work in stays quiet. Idle edges carry two faint `wire-live` comets each (3.6s) and a slow shimmer (8s); the router mark breathes and a segment orbits the router card (7s). An active edge draws itself in (0.5s ease-out), holds a breathing `mark` glow (1.6s), runs five outbound comets every 0.5s plus two lighter return comets (2.5s cycle, 1.3s ease-in-out travel), and rings the provider end on each arrival; the router turns `mark`, its halo breathes (1.8s), it ripples on each dispatch and its orbit doubles and speeds up (2.4s). A finished edge burns down: the drawn stroke retracts toward the provider and the colour settles to `last` over 2.5s. An error sends one danger shock pulse down the edge and rings the card once. No strobe, shake, turbulence or snapped state: colour changes are transitions (0.3s in, 2.5s out) and every loop eases. Where: `TopologyMotion.js`, `ProviderTopology.js`, `src/web/globals.css` (`topology-*`).
- **Topology motion stays on the compositor-friendly path**: CSS keyframes animate only `transform`, `opacity` and `stroke-dashoffset` (no SMIL, no animated filter); the one blur filter is shared from a single hidden `<defs>` and uses `userSpaceOnUse`, because an `objectBoundingBox` region is zero-width on a vertical edge and the glow vanished. Comet tails are two stacked round-capped dashes on a `pathLength="100"` path, not gradients: a gradient cannot follow a bezier, and the Route Sheet bans gradients. Dispatch ripples and arrival rings take delays from the wall clock modulo the train period, so they land with the comets on every edge however late each mounted. Budget: about 70 animated nodes for 10 idle providers and about 15 more per active edge (its idle stream is replaced). Every loop pauses (`data-motion="paused"`, `animation-play-state`) while the tab is hidden or the graph is scrolled off-screen. Where: `TopologyMotion.js` (`useMotionPause`, `syncedDelay`, `GlowDefs`).
- **Chart ticks are round steps**: integer axes step by {1, 2, 5} × 10ⁿ (2.5 only from 25), so the top tick is ≥ the max and at most 2.25× it. Where: `src/web/pages/dashboard/overview/niceTicks.js`.
- **No headless UI library**: `@ui-sdk/react` (beta) added 58 KB gzip for Menu alone and 74 KB for Dialog, Menu, Tooltip and Tabs, more than React itself, for menus and dialogs that a 40-line hook covers. Revisit at its 1.0. Where: `src/shared/hooks/useMenuKeys.js`.
- **A lazy page that fails to load reloads once**: after a deploy the old hashed chunks are gone; the first failure reloads, guarded by `sessionStorage` `lr:chunk-reload` (a timestamp, 30 s), so a persistent failure shows the "This page failed to load" boundary instead of looping. Where: `src/web/App.jsx`.
- **A new deploy is noticed from a header on API responses the dashboard already makes, with no polling and no extra requests**: every `/api/*` response carries `X-LiteRouter-Build` (the hashed entry script of the served `index.html`; omitted when the SPA is unbuilt or has no entry). One wrapper around `window.fetch`, installed once at startup, compares it on same-origin `/api/` responses with the entry script in its own document and returns the response untouched. A difference shows the "New version available" pill (a 36px chip on `raise` with a `line` border, a Reload text button and a × Dismiss for the session; no filled button, so it stays quiet in dark mode). On phones it is centred under the top bar, since toasts stack above the tab bar and would cover its buttons, and its two buttons keep a 44px tap area through an invisible `::after` while looking small; from 640px it is bottom-right. Where: `src/server/buildHeader.js`, `src/web/buildWatch.js`, `src/shared/components/shell/UpdateBanner.js`.
- **The viewport sets `viewport-fit=cover`**: iOS reports every `env(safe-area-inset-*)` as 0 without it, so the tab bar, sheets and toasts that pad by the inset would sit on the home indicator. The shell pads top, left and right by the insets and the tab bar pads the bottom. Where: `src/web/index.html`, `src/shared/components/layouts/DashboardLayout.js`, `src/shared/components/shell/PhoneTabBar.js`.
- **Install icons are PNG**: iOS ignores SVG for `apple-touch-icon` and Android install prompts want PNG, so `public/favicon.svg`, `public/icons/*.png`, `public/apple-touch-icon.png` (the path iOS probes without a link) and `public/og.png` are committed rasters of `LogoMark` on `#111212`; the maskable icon keeps the mark inside the 80% safe zone. Redraw them when the mark changes. Where: `public/`, `src/web/head.js`, `public/manifest.webmanifest`.
- **`og:image` is absolute, from the request host**: Facebook and WhatsApp ignore a relative `og:image`, and the repo has no configured public URL. `serveSpa` builds the origin from the parsed request URL (scheme `https` when `X-Forwarded-Proto` says so) and `headExtras` only interpolates it when it matches `^https?://host(:port)?$`, else falls back to `/og.png`. Reflecting the host is safe here because the HTML is `no-store` and a forged Host only changes the forger's own response. Where: `src/server/spa.js`, `src/web/head.js`.
