# Streaming, timeouts and SSE framing

## Timeouts

- **Gateway watchdogs fire before the backstop.** Headers timeout (`FETCH_CONNECT_TIMEOUT_MS` 60s, streaming), total timeout (`NON_STREAM_TOTAL_TIMEOUT_MS` 10 min, non-stream), idle timeout between chunks. `UNDICI_BACKSTOP_MS` (name kept for env compatibility; enforced by `fetchWithBackstop`) guards the raw `proxyAwareFetch` callers and is sized above every watchdog plus 30s, armed until headers and only while a body read is pending. Its abort is `TypeError("fetch failed")` with `cause` `HeadersTimeoutError`/`UND_ERR_HEADERS_TIMEOUT` or `BodyTimeoutError`/`UND_ERR_BODY_TIMEOUT` so existing 504 classifiers keep working. Where: `open-sse/config/runtimeConfig.js`, `open-sse/utils/requestTimeouts.js`, `open-sse/utils/proxyFetch.js`.
- **Stall detection measures raw upstream bytes, not transform output.** Reasoning models (Claude thinking via Kiro) can emit no SSE for long stretches while partial frames arrive. `STREAM_STALL_TIMEOUT_MS` 360s; the DeepSeek Flash lanes on opencode-go and kenari go silent after about 2 chunks, so `STREAM_STALL_TIMEOUT_FLASH_MS` is 90s. Every termination path must clear the stall timer. Where: `open-sse/utils/streamHandler.js` `createStreamController`, `pipeWithDisconnect`.
- **A 2xx non-SSE body (HTML error page) is a broken upstream.** Read it, extract the `<title>`, strip tags, clamp length, return JSON 502 (kept if upstream said 4xx/5xx). A login page means bad credential (401, account scope); the UI may render `error.message` as HTML, so upstream text never reaches the client verbatim. Combo exceptions keep message and stack server-side. Where: `open-sse/handlers/chatCore/streamingHandler.js`.
- **Health credit comes from finishing a stream, not starting one.** A stalled or broken stream must not reset backoff; a client-cancelled finalize records usage but is not an upstream success; when the stall timer or a reset wins, the error row is the only usage write. `chatCore` releases the pending counter on any throw and returns 499/504 as typed results; on a 401 refresh path a client-gone state stops before surfacing the stale 401. Where: `streamingHandler.js`, `chatCore.js`.

## SSE framing

- **`[DONE]` is synthesized exactly once and never forwarded.** An unterminated trailing `data: [DONE]` is dropped too (#5592, `data: [DONE]data: [DONE]`). Translated upstreams (Responses, Claude) send none and strict clients (OpenClaw) hang and fail over without it. Every site that writes it must mark it sent. `quirks.noDoneSentinel` (Gemini family) suppresses it (400 syntax errors); Responses clients close on `response.completed`. Where: `open-sse/utils/stream.js` `createSSEStream`, `open-sse/utils/sseConstants.js`.
- **After HTTP 200 a failure travels in-band, never as a fake finish.** `buildStreamErrorBytes`: error frame then `[DONE]` for OpenAI-compatible (openai-python raises on any `data:` with an `error` key, checked before `[DONE]`), `event: error` for Anthropic, bare error for Gemini, `response.failed` for Responses passthrough. Never fabricate a successful `finish_reason` (also in the CommandCode translator). Where: `open-sse/utils/streamHelpers.js`.
- **Finalize usage/logging on client cancel too.** A client closing right after the terminal event cancels the reader and `flush()` never runs; the tail is callable from transform, flush and cancel. Where: `createSSEStream`.
- **Bound the deferred `response.completed`.** `[DONE]` ends the wait for a usage trailer; a watchdog covers a chat upstream that stalls after `finish_reason` with neither. Where: `createSSEStream`.
- **Translated streams re-emit a heartbeat** (native `event: ping` for Claude clients, an SSE comment otherwise): Anthropic pings and upstream comments translate to nothing, so the client would time out while the stall watchdog stays quiet. Where: `createSSEStream`.
- **Ollama `done:true` is a real chunk; the `[DONE]` sentinel is not.** Ollama is raw NDJSON, so the flush path parses the leftover buffer like the transform loop. Where: `parseSSELine`.
- **Pass the upstream source format to response translators**; absent means unknown, do not defer closing events. Where: `createSSEStream`.
- **Restore renamed colliding tool names in passthrough** (fingerprint pass renames `read` to `read_client`; #4986). Where: `createSSEStream`.
- **Streamed responses carry `Cache-Control: no-transform` and `X-Accel-Buffering`** (compression skips only for `no-transform`); re-streamed upstream headers drop those describing the upstream wire encoding. Where: `sseConstants.js` `sseResponseHeaders`.
- **Sanitize chunks:** one streaming `TextDecoder` per stream (split multi-byte), skip non-JSON data lines, strip empty `tool_calls: []` (CodeBuddy CN sends it on every delta; `@ai-sdk/openai-compatible` then emits a premature `reasoning-end`). Where: `createSSEStream`.
