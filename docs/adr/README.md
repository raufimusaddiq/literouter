# Architecture decision records

Code comments are banned in this repository. The `local/no-comments` ESLint rule rejects new ones, and `.comment-baseline.json` is a ratchet that can only go down (`node scripts/comments/ratchet.mjs --check` runs in CI).

Non-obvious decisions, constraints and trade-offs that used to live in comments are recorded here instead, one ADR per topic, each with the code locations it applies to. If you are about to write a comment explaining why, write or extend an ADR.

The `/delete-comment` skill (`.claude/skills/delete-comment/`) repeats the comment audit: it classifies remaining comments, files decisions as ADRs and deletes the rest.
