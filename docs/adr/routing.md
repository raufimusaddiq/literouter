# Routing: accounts, combos, chatCore, token refresh

## Account selection and fallback

- **Failures carry a scope.** `request` (bad request: no lock, no account or combo fallback), `model` (e.g. context overflow: no lock, a combo may try another model), `account` (default: lock plus account and combo fallback). `ERROR_RULES` run top to bottom, text rules before status rules, so order is priority. Provider-scoped rules (NVIDIA NIM 400 "degraded", 15 min on the model lock) must also match on the combo path, which passes the seat's provider id with backoff level 0. 408 is a transient transport fault: short cooldown, next account. Where: `open-sse/config/errorConfig.js`, `open-sse/services/accountFallback.js` `checkFallbackError`.
- **Unmatched 4xx is returned for that request only, never cooled down.** Locking on a request-caused 400 removes a healthy account and, with one connection, every later request fails with a copy of the first error. Account-scoped statuses (401, 402, 403, 404, 429) keep their rules. Where: `src/sse/services/auth.js` `markAccountUnavailable` (`shouldRotateAccount`).
- **A client abort (499) or gateway timeout (504) never locks or rotates** (would bill the same generation again). Account attempts are capped by `MAX_ACCOUNT_FALLBACK_ATTEMPTS`. Where: `src/sse/handlers/chat.js`.
- **Provider cooldowns are capped at `MAX_RATE_LIMIT_COOLDOWN_MS` (30 min)** (Codex `resets_at` can be 5-6 h) except Antigravity's exact per-model `resetAt`, which must not be truncated; GitHub premium exhaustion lasts until the next UTC month. Backoff level is read inside the write transaction. Where: `errorConfig.js`, `auth.js`.
- **Model resolution:** combo names are checked before aliases; provider-node prefixes cannot shadow `RESERVED_PROVIDER_PREFIXES` (`cf`, `cloudflare-ai`, `openai`, `hf`...); bare `codex-auto-review` stays on OAuth Codex (#1398); a bare `claude-*` falls back from "anthropic" to Claude OAuth when no anthropic connection is active; Claude Code's `<model>[1m]` marker is stripped before resolution (the capability rides the `anthropic-beta` header). Where: `src/sse/services/model.js`, `src/sse/handlers/chat.js` `stripModelContextMarker`.
- **Errors in `chat.js` are OpenAI-shaped and re-shaped once at the top** (Anthropic for `/v1/messages`, Gemini for `/v1beta`); routes that rebuild the Request must pass `signal` through. Import only `open-sse/utils/proxyFetch.js`, not the barrel. Where: `src/sse/handlers/chat.js`.

## Combos

- **Never re-generate after a client leave or a 504**: each member call is a billed generation; a 504 may already be one. Neither is a member failure to fall past. Where: `open-sse/services/combo.js` `handleComboChat`.
- **Only the current turn decides hard capabilities** (vision, pdf, audio, video: a model lacking one drops data). Detect on the trailing run after the last assistant turn, which can span several messages; older media must not pin the combo to a vision model. Where: `combo.js` `trailingUserItems`, `reorderByCapabilities`.
- **Capacity adapter pools are an opt-in fallback.** Adapter models are prepended only when no original model satisfies the required capabilities; an enabled pool with no models is a no-op; dashboard entries start disabled; history trimmed for an adapter is capped at 80% of its context. For restricted keys only adapters the key may call are kept. Where: `open-sse/services/capacityAdapter.js`.
- **Transient 502/503 get a cooldown wait before falling through; all-members-failed returns 503, not 406** (406 says the request is invalid). Unmatched 400s are returned as-is; provider-scoped 400s rotate seats. Where: `combo.js`.
- **Fusion:** panel calls are non-streaming, tools and `stream_options` stripped (DeepSeek rejects `stream_options` without stream, #3024); the judge keeps the client's stream flag and tools, analyzes consensus/contradictions/unique insights rather than merging, and sees anonymized "Source N". Zero answers 503, one is returned directly. Panel collection uses quorum-grace: once `minPanel` succeed a short grace timer starts, bounded by a hard timeout. Where: `combo.js` `handleFusionChat`, `buildJudgePrompt`, `collectPanel`.
- **Combos must not contain themselves.** Writes reject cycles (PUT validates the merged result, not the patch); expansion also caps depth for older data. Where: `src/app/api/combos/validate.js`.
- **Combo limits aggregate members: context = min, max output = max.** The synced catalog is server-only, so `resolveCaps` accepts the server's answer and overrides only what it carries. Where: `resolveCaps`.

## chatCore pipeline

- **The endpoint follows the translated body's wire format, per model.** Use the transport matching the client's source format only if the model declares no `supportedFormats` or lists that format; otherwise the model's `targetFormat` transport, so the URL always matches the body (kimi/glm only serve `/chat/completions`; a Responses-only model must never get `input` posted to Chat Completions; decolua/9router #3418, PR #3757). Where: `open-sse/services/provider.js` `resolveTransport`, `chatCore.js`.
- **A timeout is surfaced as 504 and never replayed.** Streaming bounds time-to-headers; non-stream bounds the whole call (headers arrive only when done) and its timer must outlive `execute()` (`dispose()` is returned). Cancel a stale response before the retry sleep. A 502 from an edge is retried on a fresh socket. Where: `open-sse/executors/base.js`.
- **Stored `apiType` is authoritative for openai-compatible nodes**; only legacy nodes fall back to the node-id substring. Where: `provider.js` `resolveOpenAICompatibleApiType`.
- **Claude `tool.type` defaults to `"custom"` only when the provider declares `requireClaudeToolType`** (MiniMax 400s without it; DeepSeek 400s "unknown variant `custom`", #3905). Where: `chatCore.js` `shouldDefaultClaudeToolType`.
- **Kenari `/v1/responses` is normalized in chatCore** (same-format passthrough skips translation): `custom` tools become `function` tools, `text.format` dropped; names ride on `_customToolNames` so the non-stream handler surfaces `custom_tool_call`. Where: `chatCore.js`, `nonStreamingHandler.js`.
- **Responses upstreams always stream** (`stream:true` pinned), so non-stream clients take the forced SSE-to-JSON path; the Responses conversion in `sseToJsonHandler.js` is inlined to avoid an import cycle with `nonStreamingHandler`. Bodies with `object:"response"` skip Chat-specific post-processing. Where: `chatCore/sseToJsonHandler.js`.
- **Non-stream Claude bodies are always translated** even with `content:null` (M3 at `max_tokens:1` spends it on thinking), except bodies already carrying `choices` or non-array `content` (xiaomi-tokenplan). `reasoning_content` is stripped only when `content` is non-empty; ```json fences are stripped only when they wrap the whole answer (kimi). Finish reasons use the shared map (MAX_TOKENS to `length`, SAFETY to `content_filter`). Where: `chatCore/nonStreamingHandler.js`.
- **Strip translator-internal continuity fields (reasoning `encrypted_content` stash) before sending**; chat-native proxies answer a literal "400". Where: `chatCore.js` `stripContinuityFields`.
- **Order: cache breakpoints after every token saver; model quirks last**, just before the executor (clients send `temperature` by default, probes use tiny budgets; an earlier quirk would be undone). Where: `chatCore.js`.
- **Header hooks run before `applyAuth`** so an overlay cannot clobber the token. Where: `open-sse/executors/default.js` `buildHeaders`.
- **`getExecutor` stays synchronous** (public API) with lazily constructed specialized executors; `claudeCliVersion` resolves proxy-aware fetch lazily to avoid a cycle; pxpipe's `opts.transform` is injected by `src/` so `open-sse` stays free of filesystem concerns. Where: `open-sse/executors/index.js`.
- **Cursor's executor already emits OpenAI-compatible output**; chatCore must not treat it as its registry format. Where: `chatCore.js`.
- **`retry-after` in `unavailableResponse` is deliberately lower-case** (prevents duplicate headers). Where: `open-sse/utils/error.js`.
- **No retry for 504.** `DEFAULT_RETRY_CONFIG`: 408 once, 502/503 up to three times; pre-send and connect failures use the 502 entry. Where: `open-sse/config/runtimeConfig.js`.
- **Streaming forced off for image-generation models** (Google `v1internal:generateContent`); DeepSeek-TUI `-p` sends no `stream` and cannot parse SSE, so non-stream is forced only when the client did not ask for streaming; `Accept: application/json` means non-stream (AI SDK). Model-test probe budget `MODEL_TEST_TIMEOUT_MS` is 200s to first token. Where: `chatCore.js`.

## Token refresh

- **Always refresh from the latest stored tokens.** OpenAI/Codex and xAI/grok-cli rotate the refresh token on every refresh; a stale snapshot is a reuse that revokes the whole family (account logout). Re-read the connection first; on a reuse/invalid failure stop, never continue with the dead token. Where: `src/sse/services/tokenRefresh.js` `checkAndRefreshToken`, `src/app/api/usage/[connectionId]/route.js`.
- **Mutate credentials after each successful refresh inside chatCore's retry loop**, or attempt 2 reuses the consumed token (`invalid_grant`). The retry's response supersedes the original 401/403. Where: `chatCore.js`.
- **Concurrent refreshes of one credential dedupe, and only the owner persists** (N requests, one write). Locks live on `globalThis`; dedup results are keyed by the consumed token and pruned on access. Where: `open-sse/services/oauthCredentialManager.js`, `open-sse/services/tokenRefresh/dedup.js`.
- **The proactive refresher starts only from `initializeApp` and is fail-open** (a tick error never kills the interval). Where: `src/sse/services/backgroundTokenRefresh.js`.
- **Background refresh is sequential with delays and never eagerly resolves a Google projectId** (bursting trips Google Cloud anti-abuse); `getProjectIdForConnection()` resolves lazily. Where: `backgroundTokenRefresh.js`, `src/sse/services/tokenRefresh.js`.
- **Session and combo rotation caches share one `globalThis`-anchored TTL/LRU helper** (`createTtlLruMap`) so `bun --hot` reloads neither drop session state nor leak duplicate `setInterval` sweepers, and hot entries refresh recency on read. Where: `open-sse/utils/ttlLruMap.js`, `open-sse/utils/sessionManager.js`, `open-sse/executors/opencode.js`, `open-sse/utils/kiroSessionReplay.js`, `open-sse/services/combo.js`.
