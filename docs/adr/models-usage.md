# Model catalog, capabilities, pricing and quota

## Token accounting

- **`prompt_tokens` is cache-inclusive.** `canonicalizeUsage()` folds Claude's cache-exclusive `input_tokens` (check both `cache_read_input_tokens` and `cache_creation_input_tokens`; a first write has only the latter); OpenAI/Gemini/Ollama already include it. Idempotent: output always carries `cached_tokens` (even 0), which is the marker that stops a second fold. `total_tokens` is recomputed. Nested `prompt_tokens_details.cached_tokens` is accepted, otherwise codex and grok-cli lose cache counts. Where: `open-sse/utils/usageTracking.js`.
- **Claude to OpenAI must not double count (#130).** `message_start` has input plus cache, `message_delta` only output: merge field-wise by max (`mergeUsage`) with a `Number.isFinite` guard (`Math.max(x, NaN)` poisons it). Reverse direction splits the cache-inclusive prompt back into Claude's exclusive `input_tokens` plus cache fields. `completion_tokens_details.reasoning_tokens` is already inside `output_tokens`. Where: `translator/response/claude-to-openai.js`, `nonstream-to-claude.js`, `openai-to-claude.js`.
- **Clients see usage exactly as reported; estimates are internal and never overstate.** A missing usage is estimated at stream end and flagged `estimated`. OpenAI clients get a trailing usage chunk (`choices: []`) only with `stream_options.include_usage`; Claude/Responses/Gemini need it on the terminal event. The SSE-to-JSON handler re-attaches usage explicitly. Where: `open-sse/utils/stream.js` `emitIncludeUsageChunk`.
- **Per-shape extraction**: Responses `input_tokens_details.cached_tokens` is cache-inclusive; Antigravity/gemini-cli wrap in `{ response }`; Ollama uses `prompt_eval_count`/`eval_count`/`prompt_eval_cached_count`; translators may store OpenAI or Claude names (#3890). Only a request that failed with no usage is stored with zero tokens, flagged `error`. Where: `chatCore/requestDetail.js`, `translator/concerns/usage.js`.
- **`saveRequestUsage` collapses rows with identical (timestamp, provider, model, connectionId, apiKey, tokens)** so a retried write does not double count. Legacy Claude rows may be cache-exclusive, so `tokenDisplay` falls back to the cache count when larger. Where: `src/lib/db/repos/usageRepo.js`, `src/web/pages/dashboard/usage/components/tokenDisplay.js`.

## Pricing

- **Rates are USD per 1M tokens; a zero row means "cost not tracked" (`TODO(<provider>)`), never "free".** Cost subtracts cached and cache_creation tokens from the cache-inclusive prompt before charging input. Pattern globs are case-insensitive, first match wins; existing `PROVIDER_PRICING` rows beat the backfill. Where: `open-sse/providers/pricing.js` `calculateCostFromTokens`.
- **Runtime catalog rates (CommandCode) overlay and beat static tables**, bounded by `RUNTIME_PRICING_MAX_MODELS`, process-local. Catalog input is untrusted: a rate above `RUNTIME_RATE_MAX` (1000 per 1M) is a unit mistake and the entry is dropped; the store is null-prototype with `Object.hasOwn` lookups (`constructor`, `toString`). Where: `pricing.js` `setRuntimePricing`, `isSaneRate`.
- **Models routed without a pricing or capability row are logged once, fail-open** (a silent $0 and the 200k/64k floor hide the gap; set size capped). Where: `open-sse/providers/trackingGaps.js`.

## Capabilities (`open-sse/providers/capabilities.js`)

- **Resolution is layered and exact entries are not merged.** `PROVIDER_CAPABILITIES` beats everything (gateway truncations: Kiro 272k, Codex OAuth 272k/372k, Copilot 32k Claude output, Devin CLI 200k GPT, SenseNova intl 262144/65536); an exact entry short-circuits the pattern table, so it must repeat the family fields it wants; catalog modalities only turn capabilities on; catalog limits never overwrite a provider override.
- **Pattern order is semantics (first glob wins, anchored, case-insensitive).** Specific before generic: vision variants (glm-4.6v) before glm-5; gpt-5.4 mini/nano (400k) before gpt-5.4 (1.05M); `:free`/`-free` before the plain id; the generic gpt-6 pattern carries the API window, not Kiro's 272k (it once published 3.9x under); `*glm-5.3*` runs above `*glm-5*` (#4544; 80% of the window drives history trimming).
- **Unknown ids must not fall to defaults that disable reasoning**: `DEFAULT_CAPABILITIES` has reasoning false, so `applyThinking` strips `reasoning_effort` (#2690). List new OpenCode Free ids explicitly; their published `context_length` must not exceed the real window (~330k, #5097). Newer Claude ids (opus 4.7/4.8/5, sonnet 5.5) need exact entries (1M, adaptive thinking); the generic `*claude*` pattern sent `thinking.type:"enabled"`, forged signed placeholders and made Sonnet 5.5 answer big Codex conversations with `stop_reason:"refusal"`.
- **The synced catalog is server-only** (the module is bundled into the browser, no `node:fs`): installed through `setCatalogSource()` into a `globalThis` slot, read through it every time (a local cache would outlive `setCatalogSource(null)`). The browser falls back to generic patterns and under-reports, so the dashboard uses the server's answer from `/api/models`. Where: `catalogOverride.js`.
- **Catalog entries are keyed by provider plus model** (short ids like `auto`/`free` are router modes in one catalog and model names in another; a router mode inherited a stranger's vision). Local ids map to upstream ids (Copilot is `github-copilot` upstream) or the daily sync skips them. The parsed copy drops when the file mtime changes (hot path is one stat). An older schema file is rebuilt, not revalidated with a 304. Where: `open-sse/providers/catalogOverride.js`.
- **Table lookups use own-property tests** (model ids are attacker-influenced). Where: `capabilities.js`.
- **Per-provider facts**: CodeBuddy.cn mirrors the gateway's product-config (server wins over plugin fallback); `thinkingCanDisable` maps to `reasoning.canDisableThinking`, not the inverse of `onlyReasoning`. Qoder exposes opaque ids (`dfmodel`, `kmodel`), so a map is required or every model gets the 200K default, and `thinkingCanDisable` is false everywhere. CommandCode uses `/alpha/generate` for every model, so family patterns must not win. DeepSeek v4.1+ has real image input; v4-pro and v4-flash-0731 accept and ignore images, so vision stays scoped to dotted v4.* releases; hyphenated `deepseek-v4-1-flash` (Kenari) is an alias (#4293). Where: `capabilities.js`.
- **Name-based vision detection is a last resort that only turns vision on** (`qwen3-vl-plus`, `glm-4.6v`); image/video generation and non-chat models are excluded first; `<digit>v` needs a dotted version so `gpt-4v` never matches. Where: `open-sse/providers/visionPatterns.js`.
- **`/v1/models` publishes `context_length` snake_case at top level** (clients guess from the name otherwise; a 372k model read as 1.05M never compacts). Combos publish the minimum across seats, expanding nested combos with a cycle guard and mapping UI aliases to provider ids. The detail route is a catch-all because ids contain a slash. A header from `fetchCompatibleModelIds` marks cross-instance fetches and skips the dynamic fetch to break loops. Where: `src/app/api/v1/models/route.js`.
- **Registry**: per-model `supportedFormats` guard the transport for multi-endpoint providers (opencode-go: kimi/glm only `/chat/completions`, minimax/qwen also `/messages`, deepseek also `/responses`); the registry oauth block is canonical for clientId/clientSecret/tokenUrl; `RISK_NOTICE` resolves at display time to avoid an import cycle. Where: `open-sse/providers/models/schema.js`, `src/shared/constants/providersDisplay.js`.

## Catalog sync and listing

- **Fast-moving catalogs (Kenari, Kilo, Venice, TokenRouter, Cursor, Cline, Qoder, CommandCode) keep only a seed list in the registry**; unknown ids route via `passthroughModels`; a `modelsFetcher` supplies live rows, and the UI falls back to static rows when the live fetch fails or is empty. Pickers collapse by model id. Where: `open-sse/providers/registry/*`, `src/shared/components/ModelSelectModal.js`.
- **Authority: Kenari for kenari, then the models.dev delta, then hand-written tables.** Every failure resolves to "no data" and keeps the last good file; exact id lookup first (`glm-4-7-flash:free` is its own entry); `KENARI_CATALOG_SYNC=off` is the kill switch. Where: `open-sse/providers/kenariCatalog.js`.
- **models.dev sync stores deltas only**, ignoring small limit differences (200000 vs 202752). Detach the previous catalog before snapshotting the hand-written tables, or each delta is relative to the last and the file erases itself in two runs. Several upstream ids normalizing to one model must not stack modalities. The etag lives in the file (avoids a ~4.3 MB re-download); parse is ~23 ms daily, no worker. Where: `src/lib/modelCatalog/sync.js`.
- **Discovery fetches are bounded, shared, never throw**: CommandCode 5s abort, 15 min cache, 60s failure backoff, single flight, one forced refresh per minute, CLI identity headers only. Where: `open-sse/services/commandcodeModels.js`.
- **Qoder silently downgrades to a different model on a wrong `model_config`**, so cache every `model_config` from the COSY-signed list (even UI-hidden `enable:false`) and route by exact key; a PAT (`pt-...`) cannot sign COSY, exchange via `openapi.qoder.sh/api/v1/jobToken/exchange` for a `jt-...` and use `api2.qoder.sh` (`api3` 403 "Login expired"); refresh upserts every entry (display names change, keys such as `qmodel_latest` do not); strip a `qoder/` prefix. Where: `open-sse/services/qoderModels.js`.
- **Bulk-add names never collide**: apikey connections upsert by name, so the planner gap-fills the smallest free `<base> <n>`. Where: `src/shared/utils/bulkAdd.js`.
- **Aliases and custom models are stored under the raw `providerId`** (`openai-compatible-chat-<uuid>/glm-4.7`), so filter by providerId; custom models stay visible when no `kindFilter`. Import `models.js` directly, not `index.js` (server deps). Where: `src/shared/components/ModelSelectModal.js`.

## Probes

- **Validation probes prove auth with the cheapest request** (invalid body triggering a fast 400): 400/529 means accepted; only 401/403 is bad; cookie providers treat any non-401/403 as valid; a 400 may be model resolution with auth passed (agentrouter "no available channel"). Provider specifics: xai returns 400 for a bad key and 403 for a valid key with no credit; Vertex raw key treats 404 as valid and 401 invalid via the global endpoint; Synthetic `/openai/v1/models` answers 200 for any Bearer so it cannot validate; iFlow `getUserInfo` takes the token as a query parameter. A missing `validateUrl` is a config error, not a bad credential. Where: `src/app/api/providers/validate/route.js`, `[id]/test/testUtils.js`.
- **Warm up one model before parallel model tests** (one token refresh; rotating tokens race); connection tests time out at 15s. Where: `src/app/api/providers/[id]/test-models/route.js`.
- **The model test is a first-token probe** (stream, stop at the first token; waiting for a full generation made slow-but-healthy models fail while still billed). Reasoning models need a real budget (1024): `finish_reason:"length"` with empty content but non-empty reasoning is a pass (#3010); a token beats a terminal `finish_reason`; an error frame inside a 200 stream surfaces verbatim; timeout is 504 "may be slow"; the SSE parser accepts LF, CRLF and lone CR and holds back a trailing CR; prefer an unrestricted key. Where: `src/app/api/models/test/ping.js`.
- **Test outcomes are stored per model with `at` (epoch ms)** because production runs at `LOG_LEVEL=WARN` and a pass leaves no trace; the error belongs to its model. Where: `src/shared/utils/modelTestResults.js`.

## Quota fetchers (`open-sse/services/usage/*`)

- **Never forward an absolute `remaining`; supply `remainingPercentage`** (`QuotaTable` reads `remaining` as 0-100: Qoder's 348 credits rendered "348%"). Vercel used 95.5/100 would show 4%; Ollama's 0..1 usage ratio becomes 0..100; MiniMax ships only `*_remaining_percent`, so synthesize total=100. Where: `ProviderLimits/utils.js` `parseQuotaData`.
- **Recurring vs one-shot**: missing `recurring` means true; one-shot packs set `recurring:false` and `resetAt` is a hard expiry ("Expires in"). CodeBuddy CN mixes refill packs (Cycle fields live, `CycleEndTime` far before `DeductionEndTime`; a gap over 2 days = refill, `REFILL_GAP_MS`) and bonus packs; never merge. Where: `services/usage/codebuddy-cn.js`.
- **Claude's OAuth usage endpoint is deduplicated, short-TTL cached per token and put on a per-token cooldown after 429** (quota only; chat unaffected); a soft failure prefers the last good read; `utilization` is percent USED; model-scoped weekly limits arrive as `limits[]` `kind:"weekly_scoped"`. Where: `services/usage/claude.js`.
- **Antigravity**: free tier has only weekly quotas and `fetchAvailableModels` misleads (missing `remainingFraction` is 0), so detect tier first; project id comes from the connection, else `loadCodeAssist` (#1271); weekly quota is best-effort and never throws. Where: `services/usage/google.js`, `antigravity-weekly.js`.
- **Kiro usage auth mirrors the chat executor**: api-key connections send bearer plus `tokentype: API_KEY`; never inject the shared placeholder `profileArn` (403); social tokens may fail quota, so report "Chat may still work". Where: `services/usage/kiro.js`.
- **Grok CLI**: the credits call needs an empty gRPC-web frame (flag 0, length 0) or grpc-status 13; the decoder fails open; depleted accounts (cap/used/prepaid 0, chat 402 `personal-team-blocked:spending-limit`) get a synthetic 1/1 row because `total===0` means unlimited in the UI; SuperGrok shared pool is one `creditUsagePercent`. Where: `services/usage/grok-cli.js`.
- **Auth and entitlement quirks**: Kimi 403 `REASON_FEATURE_NO_PERMISSION` means no usage entitlement, not an expired session (must not trip `AUTH_EXPIRED_PATTERNS` refresh loops); Copilot usage needs the GitHub OAuth token, not the copilotToken; Zed Pro/Student `model_requests.limit=0` is not a cap; Groq has no quota endpoint, so read `x-ratelimit-*` from the models list (Go durations like "2m59.56s"; a missing header is not `Number(null)===0`); Qoder `organization` bucket is skipped at total 0; Vercel uses the known $5/month denominator. Where: `services/usage/*.js`.
- **Xiaomi MiMo weekly quota needs an account-session cookie, not the `sk-` key**: read `passToken` from MiMo Desktop's Electron cookie DB (copy first: it is locked while Desktop runs), SSO via passportapi, authorize `mimopc`, stamp `serviceToken` via `/api/sts`; dedupe concurrent handshakes. Where: `open-sse/shared/mimoAccount.js`.
- **Quota auto-ping counts only accepted pings.** Codex starts its 5h window after the stream completes and its `resetAt` slides while idle, so poll each tick; Claude waits for reset and a missed lead window is caught up without marking the next cycle pinged; keep a caught-up deadline on failure so the cooldown delays retry; the Codex reset-credits route generates the redeem id server side (replay). Where: `src/shared/services/quotaAutoPing.js`.
- **Gateway resellers bill at their own published rate, not the model's list price**: OpenDesign Go (go.open-design.ai/models, first input-length tier) and DeepRelay (`api.deeprelay.ai/v1/models`, peak rate for DeepSeek V4.1 Flash) get `PROVIDER_PRICING` rows that shadow the family rows; an unpublished cache rate is omitted so cache reads bill at input. Explicit zero rows (alitp-intl Token Plan ids, `k3.1-pro-highspeed`) mean "unpublished", not free. Where: `open-sse/providers/pricing.js`.
- **The OpenCode free catalog in `/v1/models` is fetched at most every 10 min** (5 s timeout, 60 s failure backoff, one in-flight), skipped under `skipDynamicFetch`, and merged with the static registry so ids without the `-free` suffix stay listed. Combo seats drop a trailing `(level)` before the capability lookup. Where: `open-sse/services/opencodeFreeModels.js`, `src/app/api/v1/models/route.js`.
- **Gemini `xhigh` survives effort-to-level mapping and is downgraded to `high` wherever the model does not advertise it** (Hydrogen is the only Gemini 4 tier with xhigh). Where: `open-sse/translator/concerns/thinking.js`, `thinkingUnified.js`.
- **Alibaba-style Anthropic streams report the pre-cache input total in `message_start` and the non-cached part with cache fields in `message_delta`**; `mergeUsage` takes the delta's input when only the delta carries cache fields. Where: `open-sse/utils/usageTracking.js`.
