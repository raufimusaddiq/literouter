# Translator (`open-sse/translator/`)

Most rules are a fix for one upstream 400 that otherwise kills the request before combo fallback can help.

## Core

- **OpenAI Chat is the pivot; an exact `source:target` pair is a direct route** (no lossy double hop: `claude:kiro`, `kiro:claude`). Same-format requests skip translation. Non-stream bodies also go provider to OpenAI to client shape. Translators self-register by import side effect; the registry is lazy `var` so circular imports hit no TDZ. Where: `open-sse/translator/index.js`.
- **Every streamed tool call carries an id, minted once per newly seen index.** Strict clients (`@ai-sdk/openai-compatible`) abort the turn on a missing id (#4992); continuation fragments stay id-less (accumulators would concatenate `call_abccall_abc`). Passthrough has no translation to carry the tool rename map, so hand it over (#4986). Where: `open-sse/utils/streamHelpers.js`, `stream.js`.
- **Unsupported features are rejected, not degraded**: `n>1` and `logprobs` with `top_logprobs` return 400 for non-OpenAI targets (response keeps choice 0), checked before the source-to-OpenAI hop; plain `logprobs:true` is ignored (IDE agents send it). Where: `translator/concerns/requestParams.js`.
- **Provider-rejected params are config rules, not code**: Claude rejects `temperature` (#1748); Copilot gpt-5.4 no `temperature`; Copilot Claude except opus/sonnet 4.6 rejects `thinking`/`reasoning_effort` (#713); gpt-5.x/6.x need `max_completion_tokens`; OpenCode Go deepseek family 400s on `response_format` (measured 2026-10-13, 12/12 fail); VolcEngine Ark caps Kimi at `max_tokens <= 32768` (min() with the model ceiling). Cloudflare Workers AI (#1926) and MiMo Desktop Preview take `content` only as a string. Where: `translator/concerns/paramSupport.js`.
- **Tool names are rewritten to `^[a-zA-Z0-9_-]{1,128}$` and mapped back** (MCP `server.tool`); already-valid names are reserved first. DeepSeek 400s "Tool names must be unique" on every endpoint (verified 2026-08-15), so exact duplicates are dropped (first wins). A dedup can orphan `tool_reference` history blocks, which z.ai rejects (code 1210), so they are removed, leaving a text note if nothing remains. Where: `translator/concerns/toolNames.js`, `open-sse/utils/toolDeduper.js`.
- **Fill missing tool responses** with "[No response received]"; fallback Responses call ids use a per-process sequence (a tight loop shares one `Date.now()`). Where: `translator/request/claude-to-openai.js`, `formats/responsesApi.js`.
- **Capture thinking intent and the client session id from the original body**, before conversion strips them (`credentials._clientSessionId` for envelopes). Trailing-assistant prefill is detected per source shape. Where: `translator/index.js` `translateRequest`.
- **Model id normalization is narrow**: only `DOT_VERSION_PROVIDERS` (kiro) rewrite a hyphen between digits to a dot; a trailing `(level)` thinking suffix is split off and re-appended; Claude Code's `[1m]` is stripped (capability travels in `anthropic-beta: context-1m-2025-08-07`). Where: `open-sse/config/providerModels.js` `findModel`.
- **`max_tokens` uses the model's real ceiling** (Opus 4.8 = 128000, default 64000) and must stay strictly above `thinking.budget_tokens`: `applyThinking` runs after the clamp and a max-effort budget of 128000 can exceed it (raise `max_tokens`; if the budget alone meets the ceiling, shrink the budget). Where: `translator/formats/maxTokens.js`, `formats/claude.js` `prepareClaudeRequest`.
- **Non-stream shape converters are shared** by the JSON and forced-SSE handlers so they cannot drift; Responses `status` is only completed|incomplete|failed; a refusal maps to `content_filter`, never `stop`. Where: `translator/concerns/nonstreamShapes.js`, `finishReason.js`.
- **Payload hygiene**: detect OpenAI before Claude (a `/v1/chat/completions` body with `input[]` is OpenAI; Cursor CLI sends Responses there); drop an empty `tools` array (Qwen); replace lone UTF-16 surrogates with U+FFFD (kenari 400); the OpenAI tool role is text-only, so tool_result images ride an `image_url` block on the next user turn. Where: `translator/formats.js`, `utils/wellFormedJson.js`.

## Claude

- **Re-anchor `cache_control` last**, after normalization, tool dedupe and every token saver; client markers are dropped. Last tool and last system block at 1h, last assistant turn at 5m, and the final tool-results turn at 5m when budget allows. Where: `formats/claude.js` `anchorClaudeCache`.
- **Max 4 `cache_control` markers.** Head anchors (system, tool) are applied first and always held; trimming keeps them and gives remaining slots to the tail-most others (a plain "last 4" rule would drop the head anchors). Where: `capCacheControlBlocks`.
- **A tool with `defer_loading` never carries `cache_control`** (400, #3567): anchor the last cacheable tool; strip invalid pairs before the budget guard. `thinking`/`redacted_thinking` blocks never get it. Where: `lastCacheableToolIndex`, `markLastCacheableBlock`.
- **Fold mid-conversation system messages in place**, never hoist into `body.system` (volatile content ahead of the conversation breaks the prefix cache). Wrap bare `content:{block}` objects first; folds are copy-on-write because the body is reused across account-fallback attempts. Where: `normalizeClaudePassthrough`.
- **Tool `type` defaults to `"custom"` only for providers with `quirks.requireClaudeToolType`** (MiniMax 2013). DeepSeek's Anthropic endpoint accepts only `web_search_*` (`quirks.claudeSupportedToolTypes`, keep `type` intact; #3905). Where: `translator/concerns/toolCall.js`.
- **Never forward a history Anthropic rejects** (mixed combos leak foreign shapes): `server_tool_use` ids must match `^srvtoolu_[a-zA-Z0-9_]+$` (z.ai/glm emits `call_`), drop their orphaned results, thinking blocks with non-Claude signatures, empty text blocks and emptied messages (never pad). `container_upload` counts as content (#4316). Each `tool_use` needs its `tool_result` in the next message, results first. Where: `formats/claude.js` `hasValidContent`, `hasForeignServerToolUseId`, `fixToolUseOrdering`.
- **A request must not end on an assistant turn** unless the client chose it (newer models 400 "assistant message prefill"); restore "Continue." only for emptied trailing user turns; mid-conversation system text is wrapped in `<instructions>` as a user turn. Where: `ensureTrailingUserTurn`.
- **Thinking rules**: Haiku 3.x/4.x reject `thinking.type:"adaptive"` and `output_config.effort`, Haiku 5+ accepts only adaptive (#5183; version can precede or follow "haiku"); MiniMax rejects `output_config`; DeepSeek needs a thinking block but not the signed fallback (PR #3332); models that can disable thinking need explicit `thinking:{type:"adaptive"}` plus `output_config`, since `output_config` alone leaves thinking off on Opus 4.6/4.7/4.8 and Sonnet 4.6. Where: `isAdaptiveThinkingUnsupported`, `thinkingUnified.js`.
- **Rejection fallback**: instead of a per-model table, `adaptClaudeRequestAfterRejection` adapts once from the upstream message (`tool_choice` any/tool unsupported, thinking disabled unsupported). Where: `open-sse/utils/claudeRequestFallback.js`.
- **OpenAI to Claude tools**: sanitize names; treat loose `{function:{name}}` as a function tool (MiniMax M3 rejects `name:"undefined"`, #2435); `tool_choice` only auto|any|tool|none, never OpenAI's "function"; `parallel_tool_calls:false` maps to `disable_parallel_tool_use` (invalid with "none"); always emit `is_error` as a bool (Zed's serde types require it). Where: `translator/request/openai-to-claude.js`.
- **Images in `tool_result` are hoisted into the user turn** for non-Anthropic Claude-compatible endpoints (OpenCode Go, Kimi, DeepSeek, GLM, MiniMax drop them). Where: `hoistToolResultImages`.
- **Anthropic-fronting `anthropic-compatible-*` nodes serving `claude-*` get the `claude` beta flags**; without `context-management-2025-06-27` upstream 400s "Extra inputs are not permitted" and the combo silently falls through. Non-Anthropic upstreams get Claude Code identity headers stripped and Bearer plus `x-api-key`. Where: `open-sse/executors/default.js` `buildHeaders`.
- **Response side**: thinking travels only in `reasoning_content` (no literal `<think>`, #3399, #4199; reasoning closes on the first text or tool call); a no-arg tool still gets a valid empty argument string; open one block per index and mint ids when missing (GLM/fireworks repeat id + null name); defer `message_delta` while usage is missing and keep closing idempotent; `stop_reason:"refusal"` becomes `content_filter` (captured 2026-09-20); merge `message_start.usage` with `message_delta.usage` so cache counts survive. Where: `translator/response/*`, `utils/bypassHandler.js`.

## Cloaking (Claude CLI and Antigravity identity)

- **`CLAUDE_CLI_VERSION` is a floor raised by a bounded npm lookup** (3 s abort, 6 h cache, 10 min failure backoff, single flight, fire-and-forget, fail open) via `proxyAwareFetch`; Anthropic rejects CLIs below a minimum (`claude_code_version_too_old`). Where: `open-sse/utils/claudeCliVersion.js`.
- **Tool suffix cloaking** (`CLAUDE_TOOL_SUFFIX`) only for `cloakToolsOnOAuth` providers with an OAuth token; typed built-ins (`web_search_20250305`) and decoy names are never suffixed. Forced `tool_choice` and `tool_reference` blocks must follow the rename. Responses must be decloaked, including same-format claude-to-claude streams (tool name is only on `content_block_start`); fallback strips a trailing suffix when the map is lost. Tool name prefix is empty (`proxy_` was a fingerprint). Where: `open-sse/utils/claudeCloaking.js`.
- **`session_id` in the cloaked `user_id` must equal `X-Claude-Code-Session-Id`**; heavy-agent betas only for opus/sonnet; `redact-thinking` blanks summaries requested with `thinking.display:"summarized"`. Where: `open-sse/providers/shared.js`.
- **Thinking signatures are validated by shape**: E-form single base64 with first byte `0x12`; R-form double base64, outer `'E'`, inner `0x12` (ported from CLIProxyAPI). Where: `open-sse/utils/claudeSignature.js`.
- **The Antigravity profile is static** (IDE Desktop 2.11.0, macOS arm64) even on Linux: it imitates the client, not the host. Where: `shared.js`.

## Thinking

- **Capture intent before translation, including "wants the text".** Claude returns thinking text only with `thinking.display:"summarized"`; for OpenAI Chat, `reasoning_effort` counts as asking (opencode, Cherry Studio otherwise saw empty `reasoning_content`); Responses uses `reasoning.summary`. Effort is read before the zai `thinking` object. Where: `translator/concerns/thinkingUnified.js`.
- **Capability rows encode live probes; per-provider rows beat global patterns, first glob wins.** Examples that would otherwise 400: OpenCode glm-5.3-flash rejects the z.ai `thinking` object (use `reasoning_effort`); OpenCode Free MiMo takes the plain effort enum and its levels entry must precede `*mimo*v2.6*`; mimo-v2.5-pro on opencode-go rejects `max`; NVIDIA NIM forced to `reasoning_effort`; `deepseek-v4.1-flash-free` rejects prompts above ~330k (#5097), so its window is 330000; Haiku 5.5 adaptive-only; Opus/Sonnet 4.6 lack `xhigh`; gpt-6.1-sol rejects `none`/`minimal`; OpenAI-compatible nodes carry `max` (#5186); codebuddy-cn publishes `reasoning.supportedEfforts` and silently clamps. Where: `open-sse/providers/capabilities.js`, `thinkingLevels.js`.
- **GLM-5.3 cannot disable thinking** (`thinkingCanDisable:false`; `enable_thinking:false` gave 400 code 1210 intermittently, #4409); `reasoning_effort` is read by z.ai only from GLM-5.2, gated per exact version; GLM-5.3 accepts low|high|max. z.ai ignores `thinking.disabled`. Where: `capabilities.js` `*glm-5.3*`, `thinkingUnified.js` zai branch.
- **Per-target emit**: Gemini effort maps to `thinkingLevel` (Gemini 3 cannot fully disable: none maps to minimal), nested under `generationConfig`, or `request.generationConfig` inside Cloud Code envelopes; Muse strict Responses needs `reasoning:{effort,summary}`; DeepSeek wire is {high,max}, declared levels win; explicit `budget_tokens` kept only for dynamic compat nodes (vLLM/SGLang); TokenRouter rejects `none`/`auto`; `providerThinking` on/off must never leak into `reasoning_effort`; tool results continue a user turn and keep its thinking intent. Where: `thinkingUnified.js` `applyThinking`.
- **Lift reasoning aliases** (`reasoning`, `reasoning_details[]`) into `reasoning_content` on every passthrough delta, before the valuable-content check; only add, never touch a delta already carrying it. `reasoning_content` is stripped from non-stream bodies only when `content` is non-empty. Where: `translator/concerns/reasoning.js` `liftReasoningAliases`.
- **Echo `reasoning_content` where required, strip where forbidden.** DeepSeek/Kimi/MiniMax need a placeholder on assistant history (#1543), including the OpenCode executor; opencode-go DeepSeek over `/messages` keeps thinking blocks and injects an UNSIGNED placeholder on tool_use turns (#3332); Groq (400) and Mistral (422) reject it; NVIDIA NIM reports a duplicate if both `reasoning` and `reasoning_content` are sent; Kimchi counts echoed reasoning as input tokens, so its executor strips real values but keeps placeholders of 8 chars or fewer. Where: `open-sse/utils/reasoningContentInjector.js`, `paramSupport.js` `stripUnsupportedParams`.
- **chatCore normalizes newer Cowork/Claude Code beta shapes** (adaptive thinking, mid-conversation system messages) before dispatch. Where: `open-sse/handlers/chatCore.js`.

## Responses API

- **`response.completed` must carry usage and output, and must be last.** Codex compacts only from its usage (counts are required i64; one missing detail drops the event; 9router#3432); output must repeat items already sent via `output_item.done` (#4307; Copilot CLI 1.0.89 reports "No response was returned"), keyed and ordered by `output_index`. Responses usage lives in `state.responsesUsage`, never `state.usage`. Where: `translator/response/openai-responses.js`.
- **Defer completion until usage is known, with a watchdog (`PENDING_COMPLETION_FLUSH_MS`, PR #4476), but only on the direct `openai:openai-responses` route**; as the second hop of a pivot `translateResponse` drops the terminal null chunk, so deferring would swallow the terminal event. Merge Anthropic `message_start`/`message_delta` usage before the intermediate chunk. Where: `openai-responses.js`.
- **`store=false` continuity**: buffer reasoning and attach `encrypted_content` to the next turn, rebuild a reasoning input item; Codex requests encrypted content explicitly. Opposite for account pools (OpenCode Free `Bearer public`, Muse Spark on OpenCode Go): strip prior reasoning items (400 "encrypted_content was not issued to this caller"). Never forward a client-scoped `previous_response_id`. Where: `translator/request/openai-responses.js`, `open-sse/executors/codex.js`, `opencode-go.js`, `opencode.js`.
- **Codex: strip server item ids** (`rs_`, `fc_`, `resp_`, `msg_`: 404 under `store=false`) and unknown fields (`routing_unsupported`; Droid's `previous_response_id`); system prompt stays in `input` as `developer` (cacheable prefix); `service_tier` "fast" maps to "priority". Where: `executors/codex.js`.
- **Tool items for strict upstreams** (#444, #393): skip nameless calls and shorten ids; filter hosted tools (no `name`) so Gemini never sees them; custom tools become functions with one `input` string and names in `body._customToolNames`; fill empty `properties`; stringify arguments once (non-JSON becomes `"{}"`); `function_call_output.output` is always a string. Where: `formats/responsesApi.js`.
- **Parallel tool calls are keyed by `item_id`**, indexed when added not when done (position attribution merges them into index 0); done emits full arguments only if no deltas were sent; `currentToolCallId` stays sticky; wait for both id and name before deciding custom vs function; custom input is emitted once at close; test `tool_calls.length`, not truthiness (codebuddy sends `[]` on every chunk). Where: `openai-responses.js`.
- **`quirks.responsesFunctionToolsOnly` (Kenari)** honors only flat function tools: convert `custom` (Codex `exec`) to functions and back, rewrite events to `custom_tool_call`, convert history (`ctc_`/`ctco_` to `fc_`/`fco_`), drop `text.format`, drop streamed argument fragments (freeform input must arrive whole). Same-format streams use a per-event rewrite hook kept in TRANSLATE mode. Where: `translator/concerns/responsesFunctionTools.js`, `utils/stream.js`.
- **Defensive inputs**: empty `input[]` becomes a placeholder user message (#389); role-only items are messages; the SSE-to-JSON handler branches on the upstream format; failed or terminal-less empty streams surface as errors, not an empty 200. Copilot `/responses` serves only OpenAI models (#1062); Headroom keeps `body.input` Responses-shaped (#1998). Where: `chatCore/sseToJsonHandler.js`.
- **A `file_id` is not an image URL and a nameless call is not a turn**: the file API is not proxied, so `input_image.file_id` has no URL form at translate time and the part is dropped (a message left with no parts is not emitted, and pending reasoning waits for the next assistant turn); a `function_call` with no name never opens an assistant turn, so `tool_calls: []` is never emitted, and its `function_call_output` is skipped with it rather than arriving as an orphan tool turn (#231, #232). Where: `translator/request/openai-responses.js`.

## Gemini and Vertex

- **`functionCall` ids must be unique across the whole history** (400 INVALID_ARGUMENT, #4532): rewrite per occurrence in document order, keep a counting `-2` suffix, pair each `functionResponse` with the emitted id, but look up the thought-signature cache by the ORIGINAL id. Tool results are queued per id (#4273) and the function NAME travels with the pair. Where: `translator/request/openai-to-gemini.js` `createToolCallIdUniquifier`.
- **Gemini to OpenAI ids**: mint unique ids when missing, pair id-less `functionResponse` with the oldest unanswered call of the same name; elsewhere `call_<name>`. Where: `gemini-to-openai.js`.
- **JSON Schema is sanitized** (one unknown keyword rejects the request, #4283): strip array/tuple keywords, `default`, `examples`, `$schema`/`$defs`/`$ref`/`const` and MCP annotation keys; convert `prefixItems` to `items`; every array gets `items`; `enum` forces `type:"string"`; walk schema-aware so a parameter named "items" survives. Where: `translator/formats/gemini.js` `UNSUPPORTED_SCHEMA_CONSTRAINTS`.
- **Rename reserved `$ref` keys in `functionResponse.response`** (read as pointers to `parts`). Where: `GEMINI_RESERVED_RESPONSE_KEYS`.
- **Gemini 4 (Argon)** has no sampling params and rejects a user turn whose last part is not `functionResponse` (#4802). Where: `isGemini4Model`, `moveFunctionResponsesLast`.
- **Cloud Code envelopes keep VALIDATED function calling** unless the client says none/required/named. Where: `explicitToolConfig`.
- **Vertex**: partner models and SA/ADC auth need project-scoped paths (RESOURCE_PROJECT_INVALID); raw keys without a project keep the projectless endpoint and resolve the id from a dummy request's 404; `?alt=sse` required; `postProcessForVertex` swaps in the Vertex thoughtSignature and strips `id` from calls and responses. Where: `open-sse/executors/vertex.js`.
- **Cloud Code project ids are fetched and cached, never random** (anti-abuse). Antigravity discovery (`loadCodeAssist`) uses the PROD host (daily rejects onboarding); chat uses the daily host to bypass prod 429. Where: `open-sse/services/projectId.js`.
- **Gemini clients get no `[DONE]`**; `/v1beta/models` converts OpenAI SSE on the fly, streaming decided by `:streamGenerateContent` vs `:generateContent`; parts with `thought:true` are never content; keep Gemini bookkeeping out of shared `state.toolCalls`. Where: `src/app/api/v1beta/models/[...path]/route.js`, `translator/response/gemini-to-openai.js`.

## RTK token saver

- **Every saver is fail-open and never grows or empties the input**: any error, timeout or panic returns null (`{ body: null, summary }` for pxpipe) and leaves the body untouched; `is_error`/`status:"error"` results are skipped to keep traces. The compressed-output memo (length + sha1, bounded LRU) caches a `null` as "keep the original". pxpipe's CPU transform cannot be aborted, so race a timer and discard a late result; never mutate the input. Where: `open-sse/rtk/index.js`, `applyFilter.js`, `pxpipe.js`.
- **Headroom `/v1/compress` speaks only OpenAI**: project Claude, Responses (`body.input`, #1998; pass `input: undefined` so the translator rebuilds it) and Kiro (`conversationState`) bodies to OpenAI, compress, copy back. The proxy route never forwards viewer credentials to a non-loopback host. Where: `open-sse/rtk/headroom.js`.
- **pxpipe savings are measured in tokens, not bytes** (base64 PNGs are bigger but images bill by pixels, Anthropic pixels/750). Host install/load is injected via `opts.transform`; the loader busts its cache per version. Where: `open-sse/rtk/pxpipe.js`, `src/lib/pxpipe/loader.js`.
- **System-prompt injection never writes a top-level `systemPrompt` for Kiro** (kiro.dev answers 400 `REQUEST_BODY_INVALID`); detect the Kiro shape by turn shape, and decide Claude/Gemini by format label first (Anthropic rejects a "system" role in `messages[]`). Where: `open-sse/rtk/systemInject.js`.
- **Headroom needs Python 3.10+**: prefer the interpreter that can see `headroom-ai` (the one next to the binary first); the pip install string comes from a closed set (`HEADROOM_COMPRESSION_EXTRAS`), no shell interpolation. Autodetect checks build output before porcelain (cargo "Compiling" is not git status). Where: `src/lib/headroom/detect.js`, `process.js`, `open-sse/rtk/autodetect.js`.
- **REA allow lives with the system-prompt injectors in `rtk/`**, not in `translator/concerns` (LiteRouter has no `systemPrompt.js`). It is off by default, runs on the final body whether or not the token-saver master switch is on, strips only paragraphs matching the client's security-policy signatures, and is fail-open and idempotent. Where: `open-sse/rtk/reaAllow.js`, `open-sse/handlers/chatCore.js`.
