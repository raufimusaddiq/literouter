# Server runtime, packaging and deploy

One `Bun.serve` process (`src/server/index.js`) serves gateway, APIs and dashboard. Operations facts live in `docs/ops.md`.

## Server

- **There is one entry point and it builds the request context** (`bun src/server/index.js`, `bun --hot` in dev). No second path may skip `trust.js`; a direct loopback request with no proxy marker and no non-loopback `Origin` is local under Bun. Where: `src/server/index.js` `startServer`.
- **Install the SIGTERM/SIGINT handler first, before `startServer`.** `initializeApp` registers `process.on("SIGTERM", () => process.exit())` and signal handlers run in registration order; when it came first, ~1/3 of runs exited 0 before the usage, request-detail and signature buffers were written. `flushAndExit` closes the DB adapter (drains buffers, checkpoints WAL), falls back to `drainRuntimeBuffersSync`, logs and continues on throw, exits 0. Synchronous on purpose; guarded by `globalThis.__lrShutdownInstalled` because `bun --hot` reruns the entry block. Where: `src/server/shutdown.js`.
- **`idleTimeout` is 255 s (Bun's maximum); paths that can stay silent longer opt out per request with `server.timeout(req, 0)`** from the route adapter after the guard (so slow-loris never reaches it): `/v1`, `/v1beta`, `/codex`, `/responses`, `/api/v1*`, console-log and usage streams, the two pxpipe routes. A new route that may be silent for over 255 s must join that list. Where: `src/server/adapter.js` `isLongLived`.
- **A client disconnect is `request.signal`** (aborts within about a second). Handlers that rebuild a `Request` must pass `{ signal: request.signal }`. An oversize body is answered 413 by Bun itself; the rejected `req.text()` that follows is expected and not logged. Where: `src/app/api/v1/responses/compact/route.js`, `src/server/index.js`.
- **h2c upgrade requests (JBR 25) are served as ordinary HTTP/1.1**; the body ceiling is `maxRequestBodySize` from `NINEROUTER_PROXY_CLIENT_MAX_BODY_SIZE` (default 128mb; LLM clients send long context and base64 images, #1529, #1572), so an h2c request buffers no more than any other. Where: `src/server/bodyLimit.js`.
- **Startup work is server-only and deferred** so the first HTTP request is not starved; background bootstrap starts from `runBootOnce` (`global.__appBootstrapped` guard); the scheduler stays absent unless an account opted in. Where: `src/server/boot.js`.
- **`Response.json` is patched globally** so it answers `application/json` without Bun's `;charset=utf-8`; API clients compare it exactly. Only that exact default is rewritten; caller-set content types stay. Where: `src/server/http.js`.
- **The system CA store is opt-in (`LITEROUTER_SYSTEM_CA=1`, set in the Dockerfile) and fails closed.** Bun verifies against bundled roots, not the OS bundle. `useSystemCaStore` runs once from the `import.meta.main` block (not `startServer`), sets the `node:tls` defaults and wraps `fetch` to add `tls.ca = system` unless the caller passed a non-empty `ca` (Bun treats `ca: []` as unset; put `ca` after the `tls` spread). Bun 1.4.4: `fetch` ignores `tls.setDefaultCACertificates`, `NODE_EXTRA_CA_CERTS` is additive only, `--use-system-ca` changed nothing. An empty or unavailable system store throws, so the server refuses to start. `proxyFetch.js` captures native `fetch` at load, so the CA list is shared via `Symbol.for("literouter.systemCaList")` (`open-sse` must not import `src/`). Idempotent via a symbol-stored original; `__lrSystemCaInstalled` guards `--hot`. Where: `src/server/ca.js`, `open-sse/utils/proxyFetch.js`.

## Packaging

- **The SPA builder is imported through a runtime-built specifier** (`["..","web","build.js"].join("/")`): `Bun.build` follows literal and constant-folded `import()`, which would pull `bun-plugin-tailwind` and the native oxide/lightningcss `.node` files into the server bundle (2.27 MB vs 1.47 MB). Version readers use `import { version } from "package.json" with { type: "json" }` so the manifest is tree-shaken. Where: `src/server/spaBuild.js`.
- **Bundled and compiled runs find assets next to themselves** (`isCompiled`: `import.meta.dir` contains `$bunfs` or `~BUN`; `isBundled`: `LITEROUTER_BUNDLED=1`), count as production (no dev build, no `fs.watch`), and env overrides still win. Where: `src/server/paths.js`.
- **Compiled executables**: assets outside the build `root` embed under their basename; `compileApp` passes absolute `[<root>/public, <stage>/web]`. `stat`/`Bun.file` work on `/$bunfs/root/...` but `realpath` throws ENOENT, so `static.js` skips realpath containment only for a real embedded root (lexical traversal checks always apply; a real on-disk dir named `~BUN` keeps realpath). Compile sets `autoloadDotenv: false` and `autoloadBunfig: false` (else a stray `.env` in the cwd is read). `Bun.build` throws `AggregateError` unless `throw: false`. Where: `scripts/build.mjs`, `src/server/static.js`.
- **Subprocesses use the executable as `bun` via `BUN_BE_BUN=1`** (`bunCommand()`); `process.execPath` is the app itself in a compiled run. A spawn without it starts a second server. The smoke script deletes it when starting the executable as a server. Where: `src/lib/runtimeBun.js`.
- **Docker**: builder runs on `$BUILDPLATFORM` and cross-compiles musl; runner user `literouter` has uid/gid 1000 (the old `node` ids, so `/app/data` volumes keep ownership; busybox `ps` truncates names, so smoke asserts `Uid: 1000`). Memory is capped with `mem_limit` (V8's `--max-old-space-size` does nothing on JavaScriptCore); `BUN_OPTIONS=--smol` is opt-in. Size budget: image 150 MB limit (116.3 MB measured). Where: `Dockerfile`, `compose.production.yml`, `scripts/check-image-size.mjs`.
- **Musl native packages (`@tailwindcss/oxide-linux-x64-musl`, `lightningcss-linux-x64-musl`) are not pinned**; if a release stops resolving them on Alpine, restore only that optional dependency (image smoke fails first).
- **Staging and production images are separate**: staging publishes `-staging:staging-<sha>`; `deploy.sh` accepts only `-production:production-<40 hex>`. `test.yml` is reusable (`workflow_call`) and concurrency groups differ (`test-<ref>`, `staging-image`) so the caller cannot deadlock on the callee. Deploy must block on health (compose returns while `starting`) and never remove the old tag before the new one is verified. Where: `.github/workflows/`, `scripts/deploy.sh`.
- **No Node anywhere**: `.github`, `scripts`, `Dockerfile` and `cli` (excluding `cli/test` and `*.md`) contain no `node`/`npm`/`npx` invocation or node shebang; guarded by a test. Where: `tests/unit/no-node-anywhere.test.js`.
- **Benchmark mock upstream replies inline at delay 0** (`setTimeout(0)` quantises to ~15 ms on Windows and hides gateway overhead). Where: `scripts/bench/mock-upstream.mjs`.
